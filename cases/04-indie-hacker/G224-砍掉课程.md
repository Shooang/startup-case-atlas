## 故事正文

Lane Wagner 做 Boot.dev 的时候是后端开发管理者。他注意到一件事：入门级开发者的数量在增加，但招聘到的质量似乎在下降。

他的判断是，成为优秀开发者不需要学位，但需要一个坚实的基础，这至少需要三个月以上来建立。Boot.dev 让学生用 Python 学后端，产品由二十多个课程和项目组成，学生通过写真实代码完成，学习周期按十二个月设计。他还有一个观察：世界上后端开发者的数量是前端的两倍，但很少有在线学习平台有效地服务这批人。

第一个版本他做错了顺序。几个月里，他用 Golang、Vue.js、Postgres 从头写了一个定制课程平台，然后上线第一门 Go 语言课程。问题是，他没有营销渠道。他后来说，还不如先开一个 YouTube 频道聊 Go 和后端工程，先熟悉受众和客户基础，而不是先造一个"现在已经不存在"的 v1。

产品里还有一套奇怪的游戏系统：学生买宝石，用宝石换课程，课程表现好可以拿折扣。事实证明大多数人只想买课，宝石让人困惑，增加了阻碍。改成直接卖会员之后，收入立即涨了 2 到 3 倍。

创业初期他没有计划、没有营销预算、没有社交媒体粉丝，有好几个月没有客户。他最后靠博客长起来：文章在谷歌的编程相关词上排名很高，他基本是自学成才的 SEO 博主。这部分带来每月几千美元，但转化率非常糟糕——查"如何在 Go 里写 for 循环"的人并不想买 Go 课程，他们拿到答案就走。

真正的转折发生在 2022 年初。他不再把产品定位成"游戏化学习"，而是完全聚焦 Python 和 Go 的后端开发，甚至删掉了一些不符合这个细分市场的课程。增长变得稳定。

此后他把 SEO 的关键词往上移，去做"学习后端开发"这类意图更高的词。播客做客和 YouTube 是不花钱的营销，但要付出时间和内容——你不能只在别人的渠道上免费宣传，得先给他们的用户提供真正有价值的东西。

上个月他赚了约两万六千美元，去年同期只有三千美元。

他说收益最好的月份，都是他们在邮件列表里做促销的月份。

## 可用观点

- 砍产品线是一种增长手段：删掉不属于细分的课程，把模糊的"游戏化学习"换成"Python 和 Go 后端"，转化才立得住
- 关键词的意图决定转化：教程类词带来流量但不带来付费，"学习后端开发"这类词才带意图
- 先有受众再建产品：他先造平台后找渠道，顺序反了，v1 最后被丢掉
