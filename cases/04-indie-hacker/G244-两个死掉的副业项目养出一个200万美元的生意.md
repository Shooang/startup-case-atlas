## 故事正文

Adam Wathan 是 Tailwind CSS 的发明者。2020 年 8 月，他在博客上回顾了这门生意是怎么来的，答案有点出人意料：它是两个死掉的副业项目的副产品。

第一个项目叫"Digest"，2015 年他和商业伙伴 Steve Schoger 想做一个公司内部分享链接的网站。他专门休假一周来做原型——结果按开发者们熟悉的老剧本，整周都花在了决定技术栈上，最后一天才开始写真正的功能。其中一个决定是 CSS：他讨厌 Sass，只能从头手写 Less 样式。

"Digest"最终和其他大多数副业一样走向墓地。除了样式表。

在之后至少 4 到 5 个新项目里，他不断复制粘贴那批 Less 文件当起点。他注意到一件事：开始只是简单的填充和边距工具，却逐渐覆盖越来越多的 CSS 特性，而组件文件越来越短——组件样式永远太"有主见"，没法换个设计复用；工具类才是真正可移植的东西。"实用至上"这个概念，就是从这时开始被定义成一种体系架构哲学的。

第二个被放弃的项目是 KiteTail，一个面向开发者的支付平台。他没有维护开源框架的打算，但一条接一条的信息流里，人们总在问：这个 CSS 能不能开源打包使用？他后来说，这就是公开构建（在直播里写代码）的好处——如果没有在又一个被抛弃的项目上直播工作，他和 Steve 永远也建立不起 Tailwind Labs 的业务。

2017 年 6/7 月起，他和 Jonathan Reinink 狂热地工作了 2-3 个月；8 月朋友 David Hemphill 建议他试试 PostCSS；2017 年万圣节之夜，v0.1.0 发布。2020 年 7 月，Tailwind 总安装量突破 1 千万次。

商业化在框架发布两年之后才来。2018 年 12 月出版的《Refactoring UI》带来一笔资金，2020 年 2 月，第一个商用产品 Tailwind UI 上线——为了赶自己定的截止日期，他们连续工作了 36 个小时。它的成功超出了他们的想象：发布约 5 个月，Tailwind UI 收入达 200 万美元；Tailwind Labs 不到 2 年总收入超过 400 万美元。

## 可用观点

- 失败项目的价值藏在副产品里：Digest 死了，但样式表活着——判断资产别只看项目是否上线，要看哪部分被反复复用
- 开源免费与商业收入是同一台飞轮的两半：1 千万次安装量是免费攒下的信任，Tailwind UI 把它直接换成 200 万美元
- 商业化时机可以晚：框架发布两年后才出第一款付费产品，验证过的分发渠道（社区）让晚入场依然打得赢
