## 故事正文

Tim Leland 做了 11 年软件开发，主要做在线支付应用。业余时间他喜欢做小项目，第一个受到关注的是一个天气浏览器扩展，有超过 20 万用户，被 Lifehacker 推荐过。那次曝光让他对做浏览器扩展上了瘾。那个扩展是免费的，可以一次性升级到"专业"功能。

2019 年 3 月，谷歌宣布关停自家的 URL 短链服务。他判断短链的需求会很大。日常工作里他也看到，短信应用需要链接缩短的 API。他认为这项服务别的公司也会需要，于是有了做短链 API 的想法。

短链最关键的部分是域名：必须短，好输入，好记，而短域名很难拿到。他在 Indie Hackers 上认识了 Park.io 的创始人——那是一个帮人注册过期域名的服务。通过合作，他拿到了 T.LY。

MVP 只花了几天。核心是一个缩短链接的 API，同时存下点击、浏览和位置的统计，并预留了一个类似谷歌短链工具的统计页面。他把 API 接进了自己的 Link Shortener 浏览器扩展。域名这么短，本身就是产品能站出来的原因。

API 跑起来之后，他才开始做允许用户注册的界面。注册后可以管理自己的链接、看私有统计、改短链的自定义结尾、绑自定义域名，也可以把其他用户加进团队，让多个员工一起管链接。

他的原始目标是让创建短链变成一次点击，所以做成了浏览器扩展，方便创建、分享和追踪。之后就是不断优化、发布、分享。API 服务上线后，他观察到有 6 万用户立刻通过扩展用上了这个服务。到 2019 年 8 月，他已经创建了 10 万个短链，追踪了数百万次点击。

增长基本是自然的：当 T.LY 的短链在 Twitter 上被分享出去，他就能看到有人在用，然后有人开始注册帐户来管理自己的链接。他也在 Indie Hackers 上持续更新进展，分享做浏览器扩展的经验。

他试过 Facebook 广告，但不确认有没有效果；他没有时间盯广告，觉得是在浪费钱。

他提到两件长期要做的事。一是保持服务简单、成本低，为此他不断优化代码、提高性能，把重定向扩展到几十亿次的量级。二是对抗滥用：很多短链服务出现过又消失了，通常是被垃圾邮件用到被互联网屏蔽。他做了自动检测恶意 URL 的系统。

周刊给出的数字是：月收入超过 2600 美元，超过 800 万个短网址，追踪超过 8000 万次点击，扩展有超过 35 万活跃用户，谷歌应用商店安装量 40 万以上。他说自己的目标是让 T.LY 在 20 多年后仍然存在。

## 可用观点

- 平台退场是被低估的窗口：谷歌关停自家短链，等于把一个已经被教育过的市场让出来，早进场比功能多更重要
- 域名就是产品：三四个字符的短链，让每一次分享都变成一次品牌曝光，获客成本被转嫁给了用户行为
- 这类生意的真正对手不是竞品而是滥用：能不能活二十年，取决于自动识别恶意链接的能力，而不是功能列表
