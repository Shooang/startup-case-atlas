## 故事正文

2021 年 5 月，Notion 发布了公共 API 的测试版，很多用户等了很久。Lean Zubrezki 之前知道 Notion，但从没在这个产品上投入太多。看到公共 API 之后，他觉得可以看看那里有什么机会。

他没直接写代码，先去研究产品本身和 Reddit、Facebook 上的社区，搞清用户怎么用。然后他意识到：把 Notion 数据库和 Google Sheets 同步，能让一些当时做不到的工作流成立。

他之前做另一个产品时已熟悉 Sheets API，所以决定试一试。他花两周做出 MVP，上架 Google Workspace Marketplace。版本有 bug，但公开之后他得以和用户对话，从那里迭代。

十天后，他有了五十个用户。把产品推给别人，和用户主动感兴趣，是两件完全不同的事；对 microSaaS 来说，你必须感觉到用户感兴趣，而不是你必须推它。

Notion2Sheets 是一个 Google Workspace 插件，主功能是把 Notion 数据库同步到 Google Sheets，此外还有循环任务、支持表格公式、把单元格的值与某个 Notion block 同步等。

一开始产品免费：可同步三个工作空间和三个数据库，每小时自动更新，也可手动运行。后来他用这些限制和几轮迭代去定义付费档。他说自己从惨痛的教训里学到，免费给得太多了，花了些时间为每一个付费点找到合适的限制和功能；他也说，付费计划上线之后，觉得应该更早做。访谈时他的 MRR 是两千五百美元；到 2023 年 5 月，插件已有 66k 安装量，月收入五千美元。

增长一直是自然发生的：他活跃在 Reddit、Twitter、Facebook 群组，试着提供价值，合适的时候提一句 Notion2Sheets。

技术上，插件用 Google Apps Script 构建，跑在谷歌的基础设施上，这本身是最大的挑战；后端是 Firebase 和 Google Cloud，负责在 Notion API 与 Google Sheets API 之间通信；邮件用 SendGrid，分析用 Mixpanel，收款用 Gumroad。

他引了一句：没有任何作战计划在与敌人遭遇后还有效。同理，"任何功能都无法在与用户的第一次接触中存活下来"。

## 可用观点

- 平台开放 API 的时刻就是窗口期：先研究社区再写代码，比先写代码更快找到那个"当时做不到"的工作流
- 免费额度是定价的一部分：给太多会把付费点抹掉，限制只能一点点试出来
- 分发跟着用户聚集地走：Reddit、Twitter、Facebook 群组不带货，但能在对的话里被看见
