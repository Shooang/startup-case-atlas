## 故事正文

Tiago 是 Podsqueeze 的创始人。这是一个帮播客生成内容的工具：从一期节目里自动产出节目笔记、时间戳、newsletter 和社交媒体帖子。

灵感来自他自己的麻烦。做播客时时间是最紧的东西，每集都要写节目笔记、标时间戳、写 newsletter 和社媒文案，这些事占掉了他大量时间。他意识到很多独立播客和播客机构面临同样的挑战，于是想做一款点一下就能生成准确内容的工具。

从 0 开始，6 个月做到月收入 1.2 万美元。前 50 个客户花了大约 3 周。

获客由几件事拼起来。第一是社交媒体：他们在 Reddit 和 Twitter 上主动接触潜在客户，并把平台提交到多个 AI 工具目录。第二是冷邮件：先找出符合目标画像的播客，再发个性化、有具体价值主张的邮件，强调能省多少时间。第三是口碑和留存：早期用户觉得有用就继续用，也带来自然推荐。第四是在 Product Hunt 发布，为此他们调整渠道、优化落地页、确保使用流程顺畅，发布当天带来了明显的曝光和访问。

技术栈方面，后端用 Python 加 Google Cloud Functions 处理内容生成，数据库用 Firebase 实时数据库，前端用 React 加 TailwindCSS，前端部署在一个静态托管平台上。他也说了代价：Cloud Functions 有执行时间限制，处理超时会导致中断或不完整的输出；后端由平台管理，出现意外问题时可控性有限。

他得到的最重要的一条经验是，没有放之四海而皆准的成功公式。过去他参与过几个能产生收入的项目，于是相信在这些项目上投入更多时间就会带来更大回报，但这个方法后来被证明是错的。他现在的判断是，从一开始就找到有希望、能立刻看到起色的东西很关键，同时要持续试错，避免陷在局部最优里。

冷邮件对 Podsqueeze 很有效，但他明确说，这不代表它对别的产品也有效。方法要按产品试，试完要看结果。

## 可用观点

- 前 50 个客户靠的是手工作业，不是渠道复用
- 冷邮件有效的前提是收件人画像足够窄，播客就是这种窄人群
- "多投入时间就有更多回报"是创业者最容易自我说服的错误
