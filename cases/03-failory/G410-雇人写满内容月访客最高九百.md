## 故事正文

Michael Hebenstreit 是德国法兰克福一家媒体公司 Array Internet 的创始人兼 CEO，主业是给国际客户做网站开发、线上营销和 SEO。他旗下最成功的业务是 MH Themes，一套面向在线杂志、新闻站和进阶博客的 WordPress 主题，覆盖 110 多个国家的两万多个客户。

Gameslog 是他几年前的一个尝试。

那时他对联盟营销越来越感兴趣。他手上已经在运营几个线上杂志，但没有做过联盟站。有一天他看到一家游戏站推广在线游戏，就去做了研究：不少联盟项目对"注册即玩免费游戏"这种纯线索也付不错的佣金，因为游戏公司靠卖游戏内道具变现。他的推算是：如果能把一个自己的游戏站做到合理的流量，这件事会非常赚钱。

于是他做了三件事。

第一，雇了多个写手，大量生产内容。第二，自己写功能，把在线游戏录进数据库，能按各种条件列出游戏，配截图和带联盟链接的试玩按钮。他的设想是：内容够多，再做 SEO，就能从 Google 拿到自然流量。

第三，去联系游戏制作公司谈合作换曝光。这一块效果好于预期，但很多公司不愿意和一个没有历史记录的新站做生意——他写了一句很实在的话：做生意总是容易得多，如果你已经成功。

另外他还建社媒渠道、做抽奖、试过 PPC 投放。所有内容、截图都是手工准备的，他们刻意不走 API 导入，为的是内容真正独一无二。

结果是：除了几笔成功的联盟成交、几美元 Google AdSense、以及游戏公司的几篇付费软文，这个站没有产生任何收入。流量也卡住了，每月几百个访客，他记得最高纪录大约是每月 900 个独立访客。

他的判断是，这个流量水平根本没法变现一个联盟站，尤其是在佣金本来就不高的品类里。

他把最大的劣势归给市场：做这类游戏联盟站的人已经太多了，有几家非常大、非常受欢迎的对手，想在好关键词上排上去极其困难。他说，他显然应该在开始之前做更多调研。他的错误是——他只是因为觉得好玩就想做这件事，没有先研究它是不是一门可靠的好生意。

如果重来，他说会先做彻底的调研：看竞争、分析关键词，判断自己用合理的资源有没有可能竞争。他还提了一个前提：线上生意的好处是，你在开始之前就能拿到有价值的数据，那就该用数据做决定，然后再决定做不做。

他的建议里还有一条是"永远保持专注"：如果做完了功课，就要盯住主要业务目标，按计划走，不要陷进细节和无利润的任务里。

## 可用观点

- 内容型联盟站的产量和排名不是同一件事：排名由域名权重与竞争密度决定，产量只决定你付了多少内容成本
- "因为好玩而开始"是一种高成本的决策方式，它把调研成本推迟到失败之后支付，而那时的价格是全部投入
- 对手的大小不只体现在预算，还体现在"别人愿不愿意跟你做生意"——新站没有履历，连免费的合作都难谈
