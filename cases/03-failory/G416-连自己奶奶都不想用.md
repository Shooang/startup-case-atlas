## 故事正文

Deepak Chhugani 父母是印度人，他在厄瓜多尔长大，七年前到美国读大学，职业经历几乎全在金融，最后一份工作在美银美林。他辞了职，给自己几个月做点自己的事。

Legaats 的灵感来自祖父的自传。他想把这个感觉复制给所有人：一个 Web 应用，让婴儿潮一代和老年人用视频、文字、照片，把人生中最重要的经验存下来、分类、互动地分享，传给后代。

他查过数据：到 2017 年底，美国一半人口在 50 岁以上，掌握全国 70% 的可支配收入，同时普遍承受社交孤立——Legaats 想缓解这个问题。

早期用户来自他的私人网络：告诉朋友，朋友再转告别人；他访谈一些别人会想读的高管——旧导师、朋友的父亲、熟人介绍来的——把访谈和经验片段发出去。

全职做了七个月，他决定不做了，把业务改成 The Lobby：让求职者付费和投行在职员工做一对一通话、拿建议并争取内推。

第一，验证假设太慢。他特意纠正早前的说法：当初他怪没有技术联合创始人，回头看这是错的——没有技术合伙人只拖慢了低成本做技术，他们本可以做几十个便宜的低技术实验去验证核心假设：老年人会不会通过在线产品记录人生经验来缓解孤立？对不熟技术的人，这个行为有多容易？他太执着于"做出一个数字产品给行业里的人看"。

第二，没有清晰的商业模式。他认为"先做消费级产品、等几百万用户再变现"的时代过去了；在 Facebook 和 Google 垄断广告位之后，很难再有 Yik Yak、Secret 那种崛起。Legaats 没有清晰模式，他能想到的（比如收存储费）都没被认真设计或验证。

第三，对目标用户缺乏共情。他以为所有人都会想了解自己祖先的这类东西，于是说服自己：我的体验足以驱动我把它复制给所有人。他在为一个自己无法共情的群体做方案。他喜欢读智慧型内容，却不理解让这个年龄段的人持续生产内容要付出什么。他的反问很锋利：我凭什么假设老年人靠一个 Web 应用解决孤立？也许他们只是需要家人多来看看？

第四，他不享受执行。这条他最意外。前三条本来都可以让他调整模式、或去啃一个更聚焦的问题；但他不享受执行，于是换了方向。和那些 50 岁以上的 CEO 用户头几次见面，从他们身上获得智慧像做梦；但他很快发现，"享受对话"和"让他们、也让自己把这些内容生产到线上"是两件事。教七八十岁的人写博客式文章、录自己给建议的视频，试过就知道。

最明显的红灯是：他发现自己连让亲奶奶用这个产品，都不想去推动。

第五，没有不公平的竞争优势。他一辈子做的事都和金融、商业相关，现在做的却是社交产品——这类产品的成功故事几乎都始于团队里有个很棒的开发者。他连网站怎么搭都不懂，没和工程师共事过，却以为自己能让几百万人上瘾。

## 可用观点

- 消费和生产是两件不同的事：爱读别人的人生经验，不代表那个年龄段的人愿意自己生产；中间隔着一整个技术门槛，而门槛要用共情去测量，不是用热情去跨
- 验证的成本可以极低：他后来的项目用一条无偿的 LinkedIn 状态和几张表格，没写一行代码就收到几百美元，这才是七个月里最该先做的事
- "我不享受执行"是一条合法的退出理由，它比任何市场分析都更早决定一件事能不能被做久
